# Ventic — Telegram Video Streamer & Media Hub

A modern, cinema-grade web media center built with the aesthetic of **Ventic** (`ventic/ventic`) for streaming videos from public Telegram channels directly in your browser.

100% static HTML/CSS/JS — zero backend, zero database, zero cost. Ready to deploy to **GitHub Pages**.

---

## ✨ Features

- **Ventic Aesthetic**: Deep OLED blacks, glassmorphism cards, ambient lighting glows, and 5 theme presets (*Ventic Dark, Midnight OLED, Tokyo Night, Emerald Abyss, Crimson Ember*).
- **Public Telegram Streaming**: Stream any video by pasting a public post link (e.g. `https://t.me/channel_name/123`).
- **Media Library & Playlists**: Save your favorite Telegram videos with custom titles, posters, and category tags.
- **Direct Link Sharing**: Share any stream with friends using query parameters: `https://<username>.github.io/<repo>/?v=https://t.me/channel/123`.
- **Offline History & Export**: Watch history, library saved in `localStorage` with JSON export/import.

---

## 🚀 How to Deploy to GitHub Pages in 2 Minutes

1. **Create a GitHub Repository**:
   - Go to [github.com/new](https://github.com/new).
   - Name your repository (e.g., `ventic-stream`).
   - Keep it **Public**.

2. **Upload the Files**:
   - Upload `index.html`, `style.css`, and `app.js` to your repository.

3. **Enable GitHub Pages**:
   - Go to **Settings** &rarr; **Pages** (on the left menu).
   - Under **Build and deployment** &rarr; **Branch**: select `main` (root) &rarr; Click **Save**.

Your website will be live in ~30 seconds at:
`https://<your-username>.github.io/ventic-stream/`
